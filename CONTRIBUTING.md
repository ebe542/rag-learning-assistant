# Contributing

Thank you for helping improve the RAG Learning Assistant.

1. Create a branch from `main`.
2. Install the development dependencies with `python -m pip install -e ".[dev]"`.
3. Add tests for behavioral changes.
4. Run `pytest`, `ruff check .`, and `ruff format --check .`.
5. Open a focused pull request describing the motivation and verification steps.

Please do not commit PDFs, API keys, personal learning data, or copyrighted material.
